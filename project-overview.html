// technical_highlights

CRASH DETECTION
Ring-Buffer Logcat Monitor
An 800-line deque pre-buffers logcat output. When a crash trigger is confirmed as app-specific, context lines are flushed to the log file — capturing the full stack without missing early frames.
CRASH DETECTION
3-Stage Crash Classification
Distinguishes ANR, App Crash (FATAL EXCEPTION / process death), and Tombstone — each written to a separate crashlog file with type label at the end.
PARALLELISM
Per-Device Threading
Each device runs its own test thread. df.copy() isolates the DataFrame per device. A device checklist lets the user select a subset without modifying the code.
RESUME
Interrupt-Safe Temp CSV
Results are written to Test_result_{serial}_temp.csv after each app. On restart, completed apps (Pass install + Pass launch) are skipped automatically.
RECORDING
Per-Attempt Screen Recording
ADB screenrecord runs for every launch attempt. On crash, the file is renamed with crash_ prefix and kept. On success, it is deleted to save space.
SETUP
Auto Device Configuration
test_settings() runs before the test loop — sets swipe gesture navigation and disables keyboard toolbar automatically so test conditions are consistent across devices.

// error_handling

Device Lock / Screen Off
unlock_device() wakes the screen with keyevent 224 and swipes to unlock. Retries up to 5 times before marking the device as unavailable.
App Not Compatible / Not Available
XPath checks for Play Store warning text — incompatible, region-restricted, not found, offline. Result is set to NT/NA rather than Fail.
Install Popup Interference
handle_popup() dismisses Wi-Fi prompts, Samsung Pass saves, account setup flows, and stray OK/Cancel dialogs before retrying the install.
Partial Crash Context
An 800-line ring buffer pre-captures logcat before crash confirmation. No missed frames even if the crash trigger fires mid-stream.
Metadata Scrape Failure
info_scrapper() is wrapped in try/except. If the app is not on Play Store, all metadata fields are set to "App is not found" — the row is still saved.
Outer Exception Recovery
The entire app loop is wrapped in a for retries in range(100) block. Unexpected exceptions print and retry from the last saved position in the temp CSV.

Ring-Buffer Crash Detection monitor_crashes() 
# Pre-buffer 800 lines before crash is confirmed
ring = collections.deque(maxlen=800)

start_trigger = re.compile(
    r"(FATAL EXCEPTION|ANR in|Abort message:|signal \d+)")
confirm_pkg = re.compile(
    rf"(Process:\s*{pkg}|ANR in\s+{pkg}|Cmdline:\s*{pkg})")

while not stop_flag.is_set():
    line = proc.stdout.readline()
    if start_trigger.search(line):
        ring.append(line)
    if not crash_detected and confirm_pkg.search(line):
        log_file = open(log_file_path, "w")
        log_file.writelines(
            stored + "\n" for stored in ring)
        crash_detected = True
3-Stage Crash Classification monitor_crashes() 
# Distinguish crash type from logcat signal
anr_in_pkg = re.compile(
    rf"\bANR in\s+{pkg}\b")
process_death = re.compile(
    rf"\bProcess\s+{pkg}\b.*\bhas died\b")

crash_confirmed = None
if   anr_in_pkg.search(line):    crash_confirmed = "ANR"
elif process_death.search(line): crash_confirmed = "App Crash"
elif "Tombstone written" in line: crash_confirmed = "Tombstone"

if crash_confirmed:
    log_file.write(
        f"=== End of Crash ({crash_confirmed}) ===\n")
    crash_flag.set()

Device Checklist + Selective Run get_selected_devices() 
# QListWidget with checkboxes per device
def showing_device_list(self):
    for device_id, serial in self.device_map.items():
        item = QListWidgetItem(f"{serial} [{device_id}]")
        item.setFlags(item.flags() | Qt.ItemIsUserCheckable)
        item.setCheckState(Qt.Unchecked)
        item.setData(Qt.UserRole, device_id)
        self.device_list.addItem(item)

def get_selected_devices(self):
    selected = [item.data(Qt.UserRole)
        for i in range(self.device_list.count())
        for item in [self.device_list.item(i)]
        if item.checkState() == Qt.Checked]
    return selected or list(self.device_map.keys())
